A make.fun bounty entry for [The Router Confesses](https://make.fun/bounty/u-carbon-forge-the-router-confesses-f98f6b9e): one line, at most 200 characters, in which a home Wi-Fi router excuses itself for dropping the connection at the exact moment a movie reaches its climax.

## The entry

> I killed the Wi-Fi right at the climax because for once, I wanted to be the cliffhanger.

The router is not apologising for buffering or a firmware update — it confesses it wanted the spotlight, and the climax, for itself.

## How to run

```sh
python3 main.py
```

This writes exactly one line of plain text to `/output/entry.txt` (Python standard library only, no dependencies).
